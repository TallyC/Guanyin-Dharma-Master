## 壹、 系統核心特色 (v1.5 禪修深化與儀軌升級)

1. **三稱、十稱儀軌指令夾註化（0.58em 微字排版）**：
   - 全面修正「三稱」、「十稱」等指令與聖號等大問題。
   - 經典聖號本文字體莊嚴大字（24px~28px），儀軌指令自動轉為雙行夾註小字（`0.58em` 低對比度），忠實呈現漢傳古版刻經威儀。

2. **「隨法師念誦」獨立模組（無彈窗遮蔽，直接看經持誦）**：
   - 徹底移除妨礙閱讀之彈窗，將「隨法師念誦」獨立拉至**「課誦設定抽屜」**中自由開關。
   - 點擊「開始今日定課」後直接進入經文第一頁，法鼓山僧團課誦原聲於背景同步唱念。
   - 支援閱讀時隨時一鍵開關音訊，並可隨喜展開影音畫面，點擊「返回看經文」時聲音持續播放不中斷。

3. **首頁頂部導航純淨重構（全設定融合於驚嘆號旁）**：
   - 頂部導航右側整飭為三大核心模組：
     - `[ 🙏 日課 ]`：檢視修持進度、打卡月曆與禪意迴向祝福小卡。
     - `[ ⚙️ 設定 ]`：將護眼色調、5 段階梯字級（20px~40px）、字體風格（楷/宋/黑）、段落對齊（中/左）與 5 款黑金極簡標誌完整融合為一體。
     - `[ ❗ 說明 ]`：以預設驚嘆號置於**首頁最右方**，詳列三大法器聲學物理與定課導引。

4. **補入【觀音讚偈】（讚頌大士悲智行願）**：
   - 於三大定課之【大悲發願祈願文】後、稱念聖號前，完整補入「觀音菩薩妙難思，清淨莊嚴累劫修…」四句偈頌，儀軌莊嚴連貫。

5. **法鼓山主題大字祝福迴向卡**：
   - 告別死板公文粗框，迎來宋瓷宣紙留白與特大 44px 置中墨寶祝福（平安無事、福慧增長、平安自在、大悲心起等法鼓山經典主題）。
   - 內建硃砂「福慧圓滿」方印，手機長按即可保存至相簿。

6. **法鼓山真品樟木大木魚（472Hz / 172Hz 原聲再現）**：
   - 採樣自僧團課誦 5.22 秒處純淨獨擊之樟木木魚，音高穩定不飄移（pitchVar = 0），低頻飽滿厚實。
