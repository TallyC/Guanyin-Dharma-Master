## 專案緣起與依據

觀世音菩薩與娑婆世界眾生因緣深厚。聖嚴法師曾多次開示：「**只要隨時隨地稱念觀世音菩薩聖號，修持觀音法門，就能在危難中得到救濟，在修持中開展智慧與慈悲。**」

本工具專為在家自修、大眾日課、追思祈願與定課共修所設計，特別對齊法鼓山僧團大事關懷課誦音像紀錄：
1. **觀世音菩薩普門品課誦**（影音實錄 20分12秒，#大事關懷 #誦經）
2. **大悲咒課誦**（影音實錄 8分27秒，#大事關懷 #誦經）
3. **心經課誦**（影音實錄 7分47秒，#大事關懷 #誦經）

## 核心功能與特色

### 1. 嚴謹校勘・100% 原典對齊
- 每一經卷、每一偈頌、每一字讀音，均嚴格考證法鼓山課誦本、僧團唱誦影音及 CBETA 原典（如普門品 32 偈頌、梵唄引磬節奏與大事關懷儀軌）。
- 嚴格維持原本斷句與法鼓山科判，絕不隨意自創或省略。

### 2. 三音展卷・直覺校訂
- **三音垂直堆疊**：漢語拼音（上層）、注音符號（右側）、正體國字（中央），字字嚴格對齊。
- **排版切換**：可切換「三音展卷」或「單一純經文」專注模式。
- **自由字音校訂**：點擊經文中任何國字，即可叫出校訂彈窗自訂生字注音，系統自動藉由內建轉換引擎即時換算為帶調拼音，並藉由 `SafeStorage` 離線保存。

### 3. 三門合併完整定課（去重自動連貫）
- 傳統將三門分開修持時，會反覆出現前導讚、開經偈、三皈依與迴向。
- 本工具提供【三門合併完整定課】：
  - **前導唯一次**：楊枝淨水讚 ➔ 稱念觀音菩薩 ➔ 開經偈。
  - **正行連貫念誦**：普門品長行與偈頌 ➔ 大悲咒 ➔ 心經。
  - **結尾總讚皈依**：觀音偈 ➔ 大悲發願偈 ➔ 觀音聖號 ➔ 三皈依 ➔ 願消三障迴向偈。
- 完整連貫研習，不重複前導讚，一氣呵成。

### 4. 虛擬木魚伴讀與定課打卡日曆
- **合成木魚與引磬**：內建 Web Audio API 柔和音訊合成，支援空白鍵快速敲擊，免外部載入。
- **目標設定與達標提醒**：可自由設定每日遍數，達標時清越引磬相應。
- **定課打卡日曆（🙏 合掌圖示）**：持誦圓滿後一鍵打卡，當日日曆格自動標註合掌「🙏」徽章與修持總結，激勵恆常精進。

### 5. 客製化禪意迴向小卡
- **柔和護眼設計（杜絕黑色）**：提供【暖沙禪石 (Warm Sand)】與【青瓷茶綠 (Celadon Sage)】兩款典雅色彩。
- **聚焦真誠祈願**：依現代人需求，聚焦於「迴向者」、「迴向對象」與「四大面向祝福」（身心康泰、事業順遂、學業功課、心靈安和），不列出繁瑣文字。
- **雙模輸出**：支援 HTML5 Canvas 高解析度圖檔一鍵下載（PNG），以及格式化文字快速複製分享。

## 技術架構與防禦性規格

- **純前端零相依**：HTML5 + CSS3 + 原生 Vanilla JavaScript，無需 Node.js 後端，完全支援本機雙擊直接運行（`file:///`）。
- **SafeStorage 快取**：安全封裝 `localStorage`，於本機離線安全沙盒或隱私模式下自動降級至記憶體快取，絕不噴出 SecurityError 例外。
- **音效例外防護**：所有 Web Audio API 操作皆包裹於 `try-catch`，無音效卡或權限限制時不干擾主流程。
- **全域護眼原則**：全站無刺眼高刺激死白背景，無螢光色調，以暖沙與青瓷茶綠營造寧靜沈穩的修持氛圍。

## 網站部署與使用指引

1. **本機使用**：直接以瀏覽器雙擊開啟 `index.html` 即可完整運作。
2. **靜態網站部署**：將整個資料夾上傳至 GitHub Pages、Vercel、Netlify 或任何支援靜態網頁之主機空間即可全球供眾使用。
3. **快捷操作**：
   - 鍵盤【空白鍵】：敲擊木魚並累積計數。
   - 點擊經文字元：開啟字音校訂視窗修訂讀音。
   - 點擊段落時間晶片：即時定位經文與跳轉影片時間。
